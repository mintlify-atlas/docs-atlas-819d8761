Folish is a digital sketchbook that gives you a boundless canvas to draw, sketch, and create on. Inspired by Concepts App, it combines the speed of native desktop performance (via Tauri + Rust) with the flexibility of a React-powered UI — so your lines are always smooth and your tools always responsive.

## What makes Folish different?

Folish is engineered for performance. Every stroke is rendered live on a canvas overlay using `requestAnimationFrame`, then committed to a persistent SVG scene. A velocity-smoothing algorithm adapts line quality to your drawing speed, and an RBush spatial index ensures only visible strokes are ever processed — no matter how large your canvas grows.

## Get started

<Steps>
  <Step title="Install prerequisites">
    Make sure you have [Node.js](https://nodejs.org/) v16+ and [Rust](https://www.rust-lang.org/) installed on your system.
  </Step>
  <Step title="Clone and install">
    ```bash
    git clone https://github.com/ppmpreetham/folish.git
    cd folish
    pnpm install
    ```
  </Step>
  <Step title="Run in development mode">
    ```bash
    pnpm tauri dev
    ```
    Folish opens as a native desktop window with hot-reload enabled.
  </Step>
  <Step title="Start drawing">
    Select a brush from the toolbar, pick a color, and draw on the infinite canvas. Use scroll to zoom and middle-click (or `Ctrl` + drag) to pan.
  </Step>
</Steps>

<Tip>
  To build a standalone executable for distribution, run `pnpm tauri build`. The output binary is placed in `src-tauri/target/release/`.
</Tip>
